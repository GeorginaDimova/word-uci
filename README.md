# Microsoft Word – Учи и вежбај

PWA за ученици, изработена врз основа на оригиналниот PDF материјал **„Microsoft Word – Материјали за ученици по предметот Техничко образование и информатика“**.

**Изработи:** Ѓорѓина Димова, наставник по информатика  
**Училиште:** ООУ „Страшо Пинџур“ – Неготино

## Содржина

- Текстот во лекциите го следи оригиналниот PDF материјал.
- Во лекциите не се прикажуваат screenshots од целите страници на PDF-от.
- Наместо тоа, се прикажуваат само оригиналните фотографии и screenshots од материјалот, визуелно издвоени од страницата и поставени веднаш до соодветниот текст.
- Оригиналните линкови за домашна задача, видеа и самопроценка се задржани.
- Апликацијата има PWA инсталација, offline cache, квиз и локално зачувување на напредокот.
