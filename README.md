# Microsoft Word - Материјали за ученици

PWA верзија на оригиналниот PDF материјал „Материјали за Microsoft Word“.

- Изработи: Ѓорѓина Димова, наставник по информатика
- ООУ „Страшо Пинџур“ - Неготино
- Текстот во лекциите е преземен од оригиналниот PDF.
- Сликите во PWA се извлечени од оригиналниот PDF.
- Оригиналните линкови од PDF-от до видеата и формите се зачувани.

## GitHub Pages

Во **Settings > Pages** поставете **Source** на **GitHub Actions**. Потоа workflow-от `.github/workflows/pages.yml` ја објавува PWA верзијата при секој push на `main`.

Очекувана адреса:

`https://georginadimova.github.io/word-uci/`

## PWA

Апликацијата користи `manifest.webmanifest` и `sw.js`, има икони 192x192 и 512x512 и ги кешира локалните лекции и оригиналните слики за офлајн користење. Надворешните YouTube/Forms линкови бараат интернет.
